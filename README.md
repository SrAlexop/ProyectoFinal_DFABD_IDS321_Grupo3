### Descripción del Proyecto
Solución de Business Intelligence (BI) implementada con tecnología Microsoft para el análisis de la propagación y mortalidad del COVID-19 en 20 países de Latinoamérica durante el período 2020-2022. 

El proyecto integra datos epidemiológicos de Johns Hopkins University y Our World in Data (OWID), permitiendo el análisis multidimensional mediante un Data Warehouse, un proceso ETL y un Cubo OLAP (SSAS).

### Tecnologías Utilizadas
* **Base de Datos:** SQL Server
* **ETL:** SSIS (SQL Server Integration Services) y PowerShell
* **Análisis Multidimensional:** SSAS (SQL Server Analysis Services)
* **Visualización:** Power BI

### Estructura del Repositorio
* `microsoft/`: Contiene los scripts SQL, el proyecto de ETL (SSIS) y el proyecto del Cubo (SSAS).
* `documentacion/`: Contiene el informe final en PDF y el diccionario de datos en Excel.
* `evidencias/`: Capturas de pantalla y respaldos del análisis.
* `presentacion/`: Presentación de defensa final.
